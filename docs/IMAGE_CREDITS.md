# Image credits

All photos in `public/images/` were cropped and compressed to WebP for the web (43 files, about 1.4 MB in total).
Where each one is used is listed in `src/lib/images.js`.

The people in these photos are models or members of the public, used only to illustrate the
service. **They are not our helpers**: named mechanics and drivers on the site always use
illustrated avatars (`src/lib/avatar.js`), and the footer and privacy page say so.

Sources were taken from the original download file names (Unsplash and Pexels put the photographer
and photo ID in the file name). Unsplash, Pexels and Pixabay licences allow free use without
permission; we credit the photographers anyway.
